# Gene Annotation

This directory contains a comprehensive pipeline for eukaryotic gene prediction, functional characterization, transposable element (TE) filtering, RNA-Seq-based gene expression quantification, and completeness assessment. The workflow is divided into five main bash scripts designed to be run sequentially.

## 🧬 Pipeline Overview

1. **Gene Prediction:** *De novo* gene structure prediction using **Helixer**.
2. **Functional Annotation:** Functional domain and family identification using **InterProScan**.
3. **TE Filtering:** Cleaning the annotation by removing transposable element-related genes using a curated list of TE Pfam domains.
4. **Expression Quantification:** Quantifying expression levels (TPM/FPKM) for each gene model across single or multiple organs using RNA-Seq data.
5. **Assessment:** Evaluating the completeness of the annotated protein/transcript sets using **BUSCO**.

---

## 🛠️ Prerequisites

To run these scripts, ensure the following software is installed and available in your system's PATH or cluster module system:

* **Helixer** (Highly recommended to run on a GPU-enabled node via Singularity/Apptainer, https://github.com/usadellab/Helixer)
* **InterProScan** (along with its signature databases, e.g., Pfam, PANTHER)
* **RNA-Seq Aligner & Quantifier:** **STAR** or **HISAT2** (for alignment), and **Kallisto**, **Salmon**, or **featureCounts** (for quantification)
* **BUSCO** (Benchmarking Universal Single-Copy Orthologs)


---

## 🚀 Usage Instructions

Execute the scripts in the following order. Make sure to edit each script prior to execution to match your specific file paths, cluster resource allocations, and species/lineage configurations.

### Step 1: Gene Prediction (`00_runHelixer_Sbatch.sh`)
This script uses Helixer's deep learning models to predict gene structures (exons, introns, CDS) directly from your genome assembly.

```bash
sbatch 00_runHelixer_Sbatch.sh
```

* **Input:** Purged and repeat-masked genome assembly (`.fasta` or `.fa`).
* **Output:** Predicted gene models in GFF3 format (`[genome].helixer.gff3`), along with predicted coding sequences (CDS) and translated protein FASTA files.

### Step 2: Functional Annotation (`01_runFunctional_Annotation_Sbatch.sh`)
This script runs InterProScan against the predicted protein sequence set to identify functional domains, families, and protein signatures.

```bash
sbatch 01_runFunctional_Annotation_Sbatch.sh
```

* **Input:** The protein FASTA file generated by Helixer in Step 1.
* **Output:** InterProScan results mapping protein IDs to functional annotations, including Pfam domain IDs (`.tsv`, `.gff3`, or `.xml`).

### Step 3: TE Filtering (`02_filter_annotation.sh`)
Since *de novo* predictors often identify transposable elements as protein-coding genes, this script filters the Helixer GFF3/protein files. It removes gene models containing Pfam domains associated with TEs (using a curated list of TE-related Pfam IDs).

```bash
bash 02_filter_annotation.sh
```

* **Input:** * The Helixer GFF3 and protein FASTA files (from Step 1).
  * The InterProScan TSV output (from Step 2).
  * A curated list/text file of TE-associated Pfam domains (e.g., transposase, reverse transcriptase, integrase domains).
* **Output:** A filtered, high-confidence GFF3 file and corresponding protein/transcript FASTA files stripped of TE-related models.

### Step 4: Gene Expression Quantification (`04_runKallisto_Sbatch.sh`)
This script maps RNA-Seq reads (from single or multiple organs/tissues) to the filtered gene models to estimate expression levels (e.g., TPM or FPKM) per gene.

```bash
sbatch 04_runKallisto_Sbatch.sh
```

* **Input:** * The filtered GFF3 file and/or transcript FASTA file (from Step 3).
  * Raw or trimmed RNA-Seq FASTQ files (for each organ/tissue sample).
* **Output:** A gene/transcript expression matrix containing normalized expression values (TPM/FPKM/Raw Counts) grouped by organ/tissue.

### Step 5: Quality Assessment (`03_runBUSCO_Sbatch.sh`)
This script evaluates the completeness of your filtered gene models by running BUSCO in protein mode against the curated, TE-filtered protein set.

```bash
sbatch 03_runBUSCO_Sbatch.sh
```

* **Input:** The filtered protein FASTA file from Step 3.
* **Output:** A summary text file containing the BUSCO scores (Complete, Duplicated, Fragmented, and Missing percentages) representing the quality of your annotated gene space.
