
# Whole-genome Duplications

This directory contains a multi-step pipeline designed to identify whole-genome duplication events using two complementary appraoches - analysis of **synonymous substitution rates (Ks)** and **Gene traa-species tree reconciliation**.


## 🧬 Pipeline Overview

1. **Identification of paralogous gene clusters:** Identify paralogous gene clusters using **wgd dmd**.
2. **Compute Ks for each duplicated gene pair:** Compute Ks values using **wgd ksd**.
3. **Identify prominent Ks peaks related to whole-genome duplication events in each species:**
4. **Identify whole-genome duplication dervied gene pairs:** Identify duplicated gene pairs with Ks values of 0.41 - 0.68.
5. **Perform gene tree-species tree reconciliation:** Perform this analysis using gene trees constructed for all HOGs and species tree inferred using super-matrix based approach in earlier steps by feeding them to Tree2GD.

## 🚀 Usage Instructions

Execute the scripts in the following order. Ensure you edit the header parameters and internal paths in each script before submitting them to your cluster.

### Step 1 and 2: Identify paralogous gene clusters and compute Ks values for each pair of duplicated genes (`runWGD_SBATCH.sh`)

```bash
sbatch runWGD_SBATCH.sh SPECIES_NAME.CDS.fa
```

* **Input:** A directory containing a FASTA file with CDS sequences.
* **Output:** Creates wgd_dmd and wgd_ksd directories containing results generaed by this script.


### Step 3: Identify Whole-genome duplication events (`identify_Ks_Peaks_KDE.py`)
Update the files accordingly - Cluster's Ks file generated by wgd ksd.


```bash
python3 identify_Ks_Peaks_KDE.py
```

* **Input:** Paralogous clusters identified by wgd dmd and pair-wise Ks values identified by wgd ksd.
* **Output:** Generates a Ks density distribution plot with identified Ks peaks corresponding to whole-genome duplication events along with 90% confidence intervals.


### Step 4: Identify Whole-genome duplication events
Identify duplicated gene pairs containing prominent Ks peak between 0.41 and 0.68.


### Step 5: Perform gene tree-species tree reconciliation using Tree2GD (`runTree2GD.sh`)

```bash
bash runTree2GD.sh
```

* **Input:** Species tree estimated using super-matrix based approach, all gene/HOG trees (except single-copy), and HOG and Gene ID mapping table.
* **Output:** GD annotated species tree and summary files (summarytable.txt and GDtype_stat.txt).
